# Джерела цін на пальне (SK)

## Активні

| Джерело | Що дає | Статус |
|---|---|---|
| **benzin.sk** | Ціни по станціях (краудсорс), графік роботи, бренд/адреса | Основне (`engine/sources/benzin.mjs`) |
| **Photon / Nominatim** | Координати за адресою | `engine/geocode.mjs` |

## Кандидати (адаптери-заглушки)

Каталог: [`engine/sources/adapters/`](../engine/sources/adapters/). Кожен адаптер має повертати той самий нормалізований формат станції + `unifyFuelKey()`.

| Джерело | Очікування | Нотатки |
|---|---|---|
| **OpenStreetMap / Overpass** | `amenity=fuel`, бренд, інколи `opening_hours` | Координати + зіставлення з benzin; цін зазвичай немає |
| **Сторінки мереж** (Slovnaft, OMV, Shell, MOL, Orlen) | Часто **єдина ціна мережі** або загальний прайс, рідко по станціях | Саме тут релевантний кейс «одна ціна незалежно від району» |
| **Google Places `fuelOptions`** | Ціни, якщо доступні для SK | Потрібен API key; перевірити покриття SK окремо |
| **ŠÚSR / середні ціни** | Середні по країні (вже на головній benzin.sk) | База `P0` для формули економії |

## Етика

Рідкий збір, `User-Agent` з контактом, кеш, `robots.txt` / ToS. Перед продом — лист у Kontakt benzin.sk бажаний.

## Мережева єдина ціна

Після збору `enrich.mjs` групує станції за `brand` + fuel: якщо розкид ≤ 0.002 € — прапор `network_price` і запис у `data/networks.json`.
